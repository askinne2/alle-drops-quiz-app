<decisions>
Two design decisions with no prior spec, decided here rather than deferred to the executor:

**D-52-01 — What the score line reads once `/ 60` is gone.** `.scaleBar__value` renders the exact
string `Score: {score}` (e.g. `Score: 8`). Not `{score}` alone (a bare right-aligned number opposite
the `Symptom burden` axis label is ambiguous), and not `Your score: {score}` (longer, and the page
is already in second person). `05-UI-SPEC.md` §Responsive Behavior requires `.scaleBar__value` to be
a short fixed-format string that never truncates; `Score: 8` is shorter than the `8 of 60` it
replaces, so the existing class needs no CSS change.

**D-52-02 — How the new headlines behave at 375px.** No CSS change and no new type role. Per
`05-UI-SPEC.md` §Typography lines 78-82 the band-explanation `h3` keeps
`.quizResults__message h3` unchanged (`calc(var(--font-heading-scale,1) * 1.6rem)` mobile, weight
700). That class declares no `white-space`, `overflow`, or `text-overflow`, so the longer mid
headline wraps to additional lines rather than truncating or forcing horizontal scroll. This plan
asserts the absence of those three properties in source; the rendered result at 375px is confirmed
by the blocking human browser pass in plan 05.2-05.
</decisions>
