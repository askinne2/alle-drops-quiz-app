<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| **iframe (Fly origin) → parent storefront page** | The boundary this whole plan exists to verify behaviorally. `e.origin` is the only trustworthy field in a `MessageEvent`, and it is unforgeable from outside. |
| **shop-origin script → the block's own message listener** | Any same-origin script on the storefront page — a theme app, a tracker, an injected script — can post to `window` and reach this listener. Part 3 of Gate F tests exactly this sender. |
| merchant theme editor → live navigation targets | Gate D's three settings become the destinations real patients reach. |
| verification activity → production PHI table | Every submitting exit writes a real row into the real PHI store. |
