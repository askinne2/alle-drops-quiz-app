## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| iframe (Fly origin) → parent storefront page (shop origin) | `postMessage` payload crosses; every field in `e.data` is attacker-controlled. This plan defines the validator that guards it. |
| any third-party window/opener → parent storefront page | The live handler accepts messages from any sender today. |
| merchant theme editor → block settings → `_embed_src` | Merchant-supplied values become navigation targets. |
