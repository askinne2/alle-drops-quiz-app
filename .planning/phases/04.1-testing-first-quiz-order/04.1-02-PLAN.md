<objective>
Stop Part 7 testing answers from rendering inside the "Symptom Responses" loop of both PHI answer
renderers, so they appear exactly once, in their own "Test Results" section (D-05). In
`app/routes/app.quiz-results.tsx` the Test Results section must be ADDED FIRST and the filter applied
second (D-05a) — the filter alone would silently delete testing status, year, location, and allergens
from the provider's only view of them.

Purpose: after plan 04.1-01 puts Part 7 first, `ALL_ITEMS = QUIZ_PARTS.flat()` makes testing answers
the FIRST keys in `answers_json`, so Dr. Sullivan's symptom section would otherwise open with testing
status before a single symptom. This decouples the clinical record from `QUIZ_PARTS` order and closes
the pre-existing Phase 4 duplication in `pdf.ts` in the same edit.

Output: one shared partition helper, two corrected renderers, one new losslessness guard.
</objective>
