## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| React state → `window.localStorage` | Every write in this plan crosses PHI from volatile memory to disk on a possibly-shared device |
| A completed submission → the device it was completed on | After a successful POST the clinic holds the record; the device copy has no remaining purpose and is pure residual exposure |
