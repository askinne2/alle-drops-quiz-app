## Pre-discussion scouting

Findings surfaced to Andrew before any question was asked, because each changed what the real gray
areas were:

1. **The quiz runs in a cross-origin iframe.** `extensions/quiz-block/blocks/symptom-quiz.liquid:3`
   frames `alle-drops-quiz-app.fly.dev` from the storefront; `app/routes/quiz-embed.tsx:141` sets
   `frame-ancestors *`. Any draft therefore lands in third-party / partitioned storage. The
   ROADMAP's "browser-local localStorage only" decision had no record of this constraint beside it.
2. **No storage code exists anywhere.** `grep` for `localStorage` / `sessionStorage` / `indexedDB`
   across `app/` and `extensions/` returned nothing — greenfield, no prior art.
3. **Phase 04.1 made the required file upload the third screen**, so resume has to answer for that
   branch specifically.
