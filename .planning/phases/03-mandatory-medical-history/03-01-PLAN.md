From `app/lib/quiz/types.ts`:
- `QuizQuestion` — `{ kind: "question"; id; type: QuestionType; text; subtitle?; options?: QuizOption[];
  excludeFromScore?: string[]; order: number; part: number; scoreWeight?; required?: boolean; showIf?: ShowIfCondition }`
- `QuizOption` — `{ value; label; score?; exclusive?: boolean }`
- `ShowIfCondition` — a three-member union, exactly one operator per condition:
  `{ questionId; equals: string }` | `{ questionId; includes: string }` | `{ questionId; isAnswered: true }`
- `QuizInfoBlock` — `{ kind: "info"; id; heading?; paragraphs: string[]; bullets?; order: number; part: number; showIf? }`.
  MUST NOT declare `required`, not even `required?: false`.
- `QuizItem = QuizQuestion | QuizInfoBlock`

From `app/lib/quiz/schema.ts` (pure, no DOM, already tested):
- `isQuestion(item: QuizItem): item is QuizQuestion`
- `isAnswered(question, value): boolean` — checkbox_multi/radio_multi require a NON-EMPTY array;
  `[]` does NOT satisfy a required question. text_input requires a non-empty trimmed string.
  yesno requires exactly `"yes"` or `"no"`.
- `evaluateShowIf(condition, answers): boolean` — FAILS OPEN. An unresolvable `questionId` returns
  `true`, so the item renders unconditionally. This is why reference integrity is load-bearing.
- `visibleItems(items, answers)`, `itemsForPart(parts, index)`, `visibleAnswers(items, answers)`,
  `toggleOption(question, current, clickedValue)`

From `app/lib/quiz/scoring.ts`:
- `scoreQuestion` returns 0 for both `yesno` and `text_input` — DIAG-01 and every Part 6 text field
  contribute zero even if they were in a scored list.
- `calculateTotalScore(questions: QuizQuestion[], answers)` — always called with `ALL_SCORED_QUESTIONS`.
