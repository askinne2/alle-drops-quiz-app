outbound network calls during PHI processing. `readObjectBytes` is a direct authenticated GCS read,
never a public-URL `fetch()`.

    const bytes = await readGcsBytes(file.storage_object_key);
    if (file.content_type === "application/pdf") {
      const donor = await PDFDocument.load(bytes);
      const pages = await merged.copyPages(donor, donor.getPageIndices());
      pages.forEach((p) => merged.addPage(p));
