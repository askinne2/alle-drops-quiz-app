<interfaces>
The guard's counting helper (tests/quiz-bundle-freshness.test.ts):

  const SOURCE = readFileSync(join(process.cwd(), "public", "quiz-bundle.js"), "utf-8");
  const count = (needle: string): number => SOURCE.split(needle).length - 1;

NEVER `grep -c`. The bundle is a single-line ~186KB file, so `grep -c` collapses every count to 1
and every `>= 1` gate passes vacuously. Three executors and once the orchestrator have hit this.

Marker selection rule established in Phase 3: esbuild does not mangle string literals or
property-access names, only local identifiers. So quoted strings, option values, and property names
survive minification and make trustworthy markers; local variable and function names do not.

Phase 3 recorded a size move of 185796 -> 186699 bytes for its rebuild — record the equivalent
before/after figure here.
