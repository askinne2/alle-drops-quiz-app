(app/lib/quiz/schema.ts:57-78) — a switch on `question.type` with `default: return false`.
Existing groups:
  array-shaped   -> checkbox_multi, radio_multi         : Array.isArray(value) && value.length > 0
  trimmed text   -> text_input                          : typeof value === "string" && value.trim().length > 0
  numeric        -> severity_0_3, frequency_0_4, bother_0_4 : typeof value === "number"
  yes/no literal -> yesno                               : value === "yes" || value === "no"
  plain string   -> control_0_3                         : typeof value === "string" && value.length > 0
